# 📊 Machine Learning Projects (R & Quarto)

This repository contains a collection of **machine learning projects implemented using R and Quarto**, covering both **supervised and unsupervised learning** techniques. The objective of this repository is to provide **hands-on, well-documented implementations** of core machine learning algorithms, with an emphasis on **conceptual understanding, reproducibility, and interpretability**.

Projects includes:
- Clean and well-structured R code  
- Step-by-step explanations of the underlying methodology  
- Visualizations to support model evaluation and insights  
- Quarto (`.qmd`) files for reproducible analysis and reporting
- PDF files with Quarto code representing different analysis as well.

---

## 📌 Supervised Learning

The supervised learning section focuses on predictive modeling for both **regression and classification** tasks:

### 🔹 Regression & Classification Models
- **Linear & Logistic Regression**  
  Implementation of regression techniques for continuous and binary outcomes, including model interpretation and diagnostic analysis.

- **k-Nearest Neighbors (kNN)**  
  Distance-based learning applied to both classification and regression problems, with discussion on parameter tuning and performance trade-offs.

- **Classification and Regression Trees (CART)**  
  Tree-based models designed for interpretability, including splitting criteria, pruning strategies, and performance evaluation.

- **Neural Networks**  
  Training and evaluation of neural network models to capture complex, non-linear relationships in data.

- **Naïve Bayes**  
  Probabilistic classification using Bayes’ theorem, highlighting model assumptions, strengths, and limitations.

### 🔁 Ensemble Learning Methods
- **Bagging** – Variance reduction through bootstrap aggregation  
- **Boosting** – Sequential learning to improve weak learners  
- **Random Forest** – An ensemble of decision trees for robust prediction and feature importance analysis  

---

## 📌 Unsupervised Learning

This section explores methods for discovering **hidden structure and patterns** in unlabeled data:

- **K-Means Clustering**  
  Partition-based clustering with evaluation of cluster quality and selection of the optimal number of clusters.

- **Hierarchical Clustering**  
  Agglomerative clustering techniques with dendrogram visualization and cluster interpretation.
